Library Management System

A simple Java Library Management System developed to practice Object-Oriented Programming (OOP) concepts.

Features

* Add and search books.
* Add library members.
* Borrow and return books.
* Manage loans and user information.

OOP Concepts

* Encapsulation
* Inheritance
* Abstraction
* Polymorphism

Technologies

* Java
* NetBeans
* ArrayList# Java
A simple Java-based Library Management System demonstrating Object-Oriented Programming concepts such as inheritance, abstraction, encapsulation, and polymorphism.
